本人の対戦戦績をローカルで取得し、通常ウィンドウまたは小さなオーバーレイで表示するWindows向けアプリです。OBSでの表示はオプションです。

> [!IMPORTANT]
> 非公式のツールです。仕様変更により、予告なく戦績を取得できなくなる場合があります。

## 簡単な設定方法

1. 管理者が案内する正式な配布元から `Match-Session-Overlay-x.x.x-Setup.exe` をダウンロードし、実行してインストールします。配布元が確認できないファイルは使用しないでください。
2. アプリを起動し、「公式サイトを開く」から公式ログイン画面へ進みます。
3. ログイン完了後にログインウィンドウを閉じると、ログイン中のプレイヤー情報が自動取得されます。反映されない場合は「再取得」を押します。
4. 「計測を開始」を押します。開始時点を基準に勝敗、勝率、レート増減、レートグラフが更新されます。マスター到達済みのキャラクターはMR、未到達のキャラクターはLPを自動表示します。
5. 「表示レイアウト」で表示方法を調整します。
   - `通常`: ゲーム画面の横などに置く通常ウィンドウ
   - `オーバーレイ`: ゲーム画面上へ重ねるコンパクト表示
   - `オーバーレイ固定`: 現在位置で固定
   - `オーバーレイ移動`: 一時的に移動できる状態へ切り替え
   - `MR/LP GRAPH`: レートグラフのON／OFF
   - `FONT SIZE`: 戦績の文字サイズ
   - `MR/LP AXIS SIZE`: グラフ左側のレート目盛りサイズ
   - `BACKGROUND`: 背景の透明度（0%まで設定可能）
6. 必要に応じて「ゲーム起動を検知してオーバーレイを表示する」を有効にし、対象ゲームの`.exe`を指定します。

初回にオーバーレイへ切り替えたときは移動可能です。位置を決めて「オーバーレイ固定」を押してください。次回以降は前回の位置とサイズを読み込み、固定状態で起動します。

## 主な機能

- ランク、バトルハブ、カジュアルの勝敗と勝率を切り替えて表示
- ランクのアプリ起動後MR増減と推移グラフを表示
- 戦績の取得間隔を2分・3分・5分から選択（既定は2分、2分未満には設定不可）
- 新しい対戦が30分ない場合は5分間隔へ抑制し、60分ない場合は自動停止
- 手動更新を廃止し、通信の直列化・間隔制限・エラー時の段階的な再試行を固定で適用
- グラフ表示、フォント、文字色、文字サイズ、MR軸サイズ、背景透明度を調整
- 戦績をアプリを終了せずにリセット
- Windowsサインイン時の自動起動を任意で設定
- 指定したゲーム`.exe`の起動検知を任意で設定
- OBSブラウザソース用のローカルURLを提供
- 公式サイトに合わせた14言語（日本語、英語、ドイツ語、スペイン語2種、フランス語、イタリア語、韓国語、中国語2種、ポルトガル語、ポーランド語、ロシア語、アラビア語）を内蔵
- ログインセッション、Cookie、キャッシュをアプリから削除
- アンインストール時にアプリ専用データを削除（アプリの管理範囲外に移動したファイルは対象外）
- GitHub Releasesから更新情報とインストーラーを取得し、SHA-256を照合して更新

通信は同時実行を直列化し、最短間隔・段階的バックオフ・30秒タイムアウトを固定で適用します。サーバーから429と`Retry-After`が返った場合は、その指示を尊重して再試行します。

## プライバシー

- ID・パスワードをアプリのコードで取得または保存しません。
- ユーザーコードと戦績はメモリ上で処理し、アプリ設定ファイルには保存しません。
- ログインセッション、Cookie、キャッシュは`%LOCALAPPDATA%\MatchSessionOverlay\session-data\`に保存されます。これはこのPCのアプリ専用フォルダーです。
- 表示設定は`%LOCALAPPDATA%\MatchSessionOverlay\user-data\`に保存されます。
- `%LOCALAPPDATA%`はWindowsがユーザーごとに用意するアプリ用フォルダーを表します。
- 配布ファイルには、利用者のログイン状態や戦績は含まれません。
- 「ローカルデータ」の「消去」で、このPCのログインセッション、Cookie、キャッシュを削除できます。
- 実行時データは`%LOCALAPPDATA%\MatchSessionOverlay\`に保存されます。

## 更新

アプリ起動時に更新を確認します。新しいバージョンが見つかると、「確認」を押さなくても「更新」ボタンが表示されます。

更新はGitHub Releasesからのみ取得します。アプリ起動時にGitHubの最新リリース情報を確認し、利用可能な場合に管理画面へ「更新」ボタンを表示します。更新ボタンを押すとインストーラーを取得し、公開元が示すSHA-256と一致することを確認してから再起動します。確認に失敗したファイルは実行しません。

セキュリティ上の必須更新が設定されている場合は「強制更新」と表示され、更新が完了するまで旧版の機能を利用できません。

## OBSで表示する場合

管理画面下部のURLをOBSのブラウザソースへ設定します。

```text
http://127.0.0.1:37123/overlay
```

このURLは同じPCからのみアクセスできます。
ブラウザソースの幅・高さは、アプリのオーバーレイサイズに合わせて設定してください。初期値は`320 x 92`です。アプリ側でサイズを変更した場合は、OBSのブラウザソースを再読み込みすると同じサイズで表示されます。
