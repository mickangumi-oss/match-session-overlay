# フォント設定

管理画面の「表示オプション」から、戦績の数値に使うフォントを変更できます。

- `FONT`: アプリ内のプリセットに加えて、Windowsにインストールされているフォントを選択できます。
- `STYLE`: `通常` または `斜体` を選択できます。初期値は `通常` です。
- `COLOR`: 数値の色を変更できます。

`MATCH SESSION` の見出しはレイアウト用の固定フォントで表示されます。数値用のフォントを変更しても、見出しのデザインは変わりません。

フォント名はアプリ本体へ追加保存せず、選択したフォント名だけをローカル設定に保存します。別のPCへ設定ファイルをコピーした場合、存在しないフォントはブラウザの安全な代替フォントへフォールバックします。
