# はじめて使う方へ

このページでは、インストール直後の基本操作を説明します。

## 1. インストール

1. 管理者が案内する正式な配布元から `Match-Session-Overlay-x.x.x-Setup.exe` をダウンロードします。配布元が確認できないファイルは使用しないでください。
2. ダウンロードしたインストーラーを実行し、画面の指示に従います。
3. インストール後にアプリを起動します。

Windowsの警告が表示された場合は、入手元とファイル名を確認してください。配布元が不明な再配布ファイルは実行しないでください。

## 2. 公式サイトへログインする

アプリの「プレイヤー接続」で「公式サイトを開く」を押し、公式サイトのログイン画面でログインします。

アプリがIDやパスワードを読み取ることはありません。ログイン後にログインウィンドウを閉じると、ログイン中のプレイヤー情報がアプリへ反映されます。表示されない場合は「再取得」を押してください。ログイン状態は、このPCのアプリ専用フォルダーに保存されます。保存場所は `%LOCALAPPDATA%\MatchSessionOverlay\session-data\` です。

![合成データを表示した管理画面](images/management-overview.png)

## 3. 計測を開始する

1. 「表示レイアウト」で対象の対戦種別を選びます。
   - ランク
   - バトルハブ
   - カジュアル
2. 「計測を開始」を押します。
3. アプリ起動後の勝敗数、勝率、MRまたはLPの増減が表示されます。

キャラクターごとに戦績を管理します。マスターランクのキャラクターはMR、それ以外のキャラクターはLPが表示されます。キャラクターを切り替えた場合は、切り替え後のキャラクターの記録に変わります。

ランクマッチを2試合以上記録すると、現在のキャラクターの直近20試合からMRまたはLPの中央値を計算し、「POTENTIAL MR／POTENTIAL LP」として表示します。整数で表示する際は四捨五入します。これは公式のMRそのものではなく、短期的な上振れ・下振れを確認するための参考値です。管理画面では現在のキャラクターのPOTENTIAL値と、最近の対戦5件を確認できます。

中央値は、直近のレートを小さい順に並べたときの中央の値です。たまたま強い相手に勝った、または一時的に負けが続いたといった1試合の影響を平均より受けにくいため、「今の自分のレート帯」を把握する補助になります。公式サイトのMR・LPを置き換える値ではありません。

## 4. ゲーム画面の横に表示する

「戦績ウィンドウを表示」を押すと、通常のウィンドウが開きます。ゲーム画面の横へ移動し、サイズを調整してください。

ゲーム画面上に重ねる場合は、次の手順で設定します。

1. `WINDOW MODE` の「オーバーレイ」を選びます。
2. 初回は「オーバーレイ移動」の状態で位置を調整します。
3. 位置が決まったら「オーバーレイ固定」を押します。
4. 固定中はクリックがゲームへ通過するため、ゲーム操作を妨げにくくなります。

![共通の戦績項目を縦に並べたオーバーレイ](images/overlay-vertical.png)

グラフは管理画面、横／縦の通常ウィンドウ、オーバーレイ、OBSで表示できます。ランクマッチを計測すると、MR／LPの推移を確認できます。表示項目はすべての表示先で共通です。

### ゲーム起動時に自動表示する（任意）

ゲームの起動を検知してオーバーレイを自動表示する場合は、次の2つを有効にしてください。

1. 「コンピューターの起動時にアプリを実行する」
2. 「ゲーム起動を検知してオーバーレイを表示する」

2つ目では、対象ゲームの`.exe`ファイルを指定します。検知は、Windowsへのサインイン後にアプリがバックグラウンドで起動している場合に行われます。Windows起動時のアプリ実行がOFFの場合、ゲーム起動検知も自動的にOFFになります。

「コンピューターの起動時にアプリを実行する」がONの場合、Windowsサインイン時は管理画面を表示せず、通知領域（システムトレイ）に常駐します。トレイアイコンをダブルクリックするか、右クリックメニューの「管理画面を表示」で画面を開けます。管理画面を閉じても、通常ウィンドウやオーバーレイは設定どおり表示を維持します。トレイメニューの「終了」を選ぶとアプリと表示を終了します。

### フレンドのオンライン通知を使う（任意）

オプションの「通知」で「フレンドのオンライン通知」をONにします。通知対象はFRIENDSだけで、FOLLOWINGは通知しません。

- 「常に通知」: アプリが起動していれば、管理画面を通知領域へ格納しているときやゲーム未起動時も通知します。
- 「ゲーム起動中のみ」: 選択したゲーム実行ファイルが起動しているときだけ通知します。ゲーム未起動中の変化を後から通知することはありません。

初回取得時にすでにオンラインのフレンドは通知しません。OFFLINEからONLINEへ変わったときだけ、画面右下へ1回表示します。複数人は1枚にまとめられ、通知はゲームのフォーカスやマウス操作を奪わず、5秒後に消えます。

プレイヤー状態は5分を基準に確認します。管理画面を表示している間はFRIENDSとFOLLOWINGを更新します。管理画面を閉じて通知領域へ格納した場合、通知がONならFRIENDSのみ確認を継続し、通知がOFFなら取得を停止します。手動更新は同じリストにつき60秒に1回までです。

ゲーム未起動・戦績モニター停止・アプリ操作なしの状態が6時間続いた場合と、Windowsのロック／スリープ中は、FRIENDSの取得を休止します。アプリ操作、ゲーム起動、計測開始、手動更新、ロック解除／スリープ復帰で再開します。休止中の変化を後から通知することはありません。

オンライン判定はFRIENDSの全ページを正常に取得できた時点で行います。初回取得、取得途中、通信失敗時には通知しません。アプリの終了中や公式サイトからログアウトしている間も更新されません。

通知音は初期状態では「サウンドなし」です。必要な場合は、通知カードのドロップダウンからWindows標準サウンドを選び、「試聴」で確認してください。選択した音はフレンド通知を表示するときに1回だけ再生されます。通知音量は0～100%で調整でき、PC全体やゲーム・動画・システム音の音量設定は変更しません。実際の音量はWindows側の音量との組み合わせになるため、PCがミュートの場合は通知音も鳴りません。

表示時間は3～15秒で設定できます。「通知背景」は通知だけの背景透明度で、通常ウィンドウやオーバーレイの`BACKGROUND`設定には影響しません。「サンプル通知を表示」を押すと、合成プレイヤー名を使って、現在選択中の表示時間・通知音・透明度を右下で確認できます。実際のフレンド状態は変更しません。

## 5. 表示を好みに合わせる

歯車の「オプション」では、カテゴリごとに次の設定を変更できます。

- **表示内容**: 対戦モード、共通の表示項目
- **表示形式**: 通常／オーバーレイ、横／縦
- **グラフ**: 表示ON／OFF、試合数、軸サイズ、POTENTIAL基準線
- **デザイン**: 背景透過、フォント、サイズ、通常／斜体、色
- **データ取得・連携**: 戦績取得間隔、OBSブラウザソースURL
- **アプリ設定**: 表示言語、自動起動、ゲーム起動検知
- **通知**: フレンドのオンライン通知、通知タイミング、Windows標準の通知音と試聴、通知専用音量、表示時間、通知専用背景、サンプル表示
- **メンテナンス**: ローカルデータ消去、更新確認

フォントの詳しい説明は [フォント設定](font-settings.md) を参照してください。

![カテゴリを2列で整理したオプション画面](images/options-overview.png)

## 6. OBSで表示する（任意）

OBSを使う場合は、アプリを起動した状態でブラウザソースを追加し、次のURLを指定します。

```text
http://127.0.0.1:37123/overlay
```

ブラウザソースの幅・高さは、アプリ側のオーバーレイサイズに合わせて設定してください。OBSを使わず、通常のウィンドウやゲーム上のオーバーレイだけで使用することもできます。

## 7. 計測を終える・データを消す

- 「リセット」: 現在のセッションの勝敗数と増減を0から数え直します。
- 「終了」: 計測を停止します。表示中のウィンドウは「戦績ウィンドウを表示」から閉じます。
- 「ローカルデータ」の「消去」: このPCのログイン状態、保存した対戦履歴・セッション戦績、一時ファイルを削除します。表示設定は残ります。

![合成データを表示した対戦履歴画面](images/match-history-example.png)

サイトへの負荷を抑えるため、取得間隔には安全な下限があります。新しい対戦が30分ない場合は5分間隔に伸び、60分更新がない場合は自動停止します。

## 困ったときは

### プレイヤー情報が表示されない

公式サイトでログインできているか確認し、アプリの「再取得」を押してください。ログイン状態が切れている場合は、もう一度「公式サイトを開く」からログインします。

### MR/LPが `---` と表示される

計測開始直後は基準値を取得中の場合があります。次回更新まで待ってください。表示が続く場合は一度「終了」を押してから、もう一度「計測を開始」を押します。キャラクターがマスター未到達の場合はLP表示になります。

### オーバーレイを動かせない

「オーバーレイ移動」に切り替えてから位置を調整してください。固定中はゲーム操作を優先するため、オーバーレイをクリックしても動きません。

### 更新を確認したい

アプリ起動時にGitHub Releasesを自動確認します。新しい版が見つかると管理画面に「更新」ボタンが表示されます。「確認」を押して手動確認することもできます。更新元のフォルダーを指定する機能はありません。

## 個人情報について

- ログイン状態と一時ファイルは `%LOCALAPPDATA%\MatchSessionOverlay\session-data\` に保存されます。
- 表示設定は `%LOCALAPPDATA%\MatchSessionOverlay\user-data\` に保存されます。
- セッション戦績と、その表示に必要なユーザーコード・プレイヤー名は、このPCのアプリ専用フォルダーへ保存されます。対戦履歴も同じくアプリ専用フォルダーへ保存されます。
- これらは配布ファイルではなく、このPCのアプリ専用フォルダーに保存されます。
- `%LOCALAPPDATA%` は、Windowsがユーザーごとに用意するアプリ用フォルダーを表す名前です。実際の場所を確認するには、エクスプローラーのアドレスバーに `%LOCALAPPDATA%\MatchSessionOverlay\` と入力します。
- 「ローカルデータ」の「消去」では、ログイン状態、保存した対戦履歴・セッション戦績、一時ファイルを削除できます。表示設定は残ります。
