# ウィンドウレイアウト

`WINDOW MODE`では、横向きと縦向きの2種類から選択できます。

- `横`は、選択したカードを横に並べます。
- `縦`は、同じカードを縦に並べます。
- 表示する戦績項目は通常ウィンドウ、オーバーレイ、OBSブラウザソースで共通です。向きや表示先によって選択内容は変わりません。MR RANKはこれらの表示先で共通して表示されます。管理画面の戦績モニターは確認用として7項目を常時表示し、このチェック設定の影響を受けません。
- 管理画面ではMR RANKを常時表示します。MASTER以外のランクでは順位を`—`で表示します。
- 表示設定は設定メニューへ移動しました。
- 管理画面左側にはFRIENDSとFOLLOWINGのプレイヤーカードを表示します。
- 表示項目が少ない場合はカードサイズと列数を自動調整し、グラフをOFFにするとグラフ領域を詰めます。
- グラフだけを表示する場合は外周余白とウィンドウ高さを専用サイズへ詰め、グラフを背景フレーム内いっぱいに配置します。軸とラベルの可読性を保つため、最小サイズは横向き420×220、縦向き360×220です。
- 横表示で戦績カードとグラフを併用する場合は、グラフの可読性を保つため最小サイズを520×240とします。
- 表示項目は最低1項目必要です。最後の1項目はOFFにできません。
- MR/LPグラフは横・縦の両方で表示できます。データが2点未満の場合は、平らな線ではなく待機メッセージを表示します。

通常ウィンドウとオーバーレイからは、タイトル「MATCH SESSION OVERLAY」と対戦モード切り替えを省いて表示領域を確保します。対戦モードは管理画面のオプションで選択します。横向き・縦向きのサイズと位置はレイアウトごとに保持されます。
