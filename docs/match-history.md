# 対戦履歴

管理画面の「対戦履歴」から、公式サイトで取得できる最新の対戦履歴をローカルに保存できます。自分の履歴は最大5000件、ほかのプレイヤーはプレイヤーごとに最新100件を保存します。ほかのプレイヤーについて100件を超えた古い履歴は自動的に整理されます。

1. 公式サイトへのログインを完了し、管理画面でログイン状態を確認します。
2. 「対戦履歴」を開き、「100件を取得」を押します。公式サイトの10件/ページを最大10ページ、通信間隔を空けて順番に取得します。
3. 開始日・終了日、対戦モード、使用キャラクターを指定すると、保存済みの履歴だけを絞り込めます。
4. 期間内の勝敗、勝率、最大連勝、最大MR/LP、勝敗グラフ、対戦一覧を確認できます。

「勝敗の推移」は常に末尾7日分のカレンダー領域を使用します。日付フィルターの終了日、最新の対戦日、対戦がない場合は現在日の順で終点を決め、試合がある日だけ実際の日付位置に積み上げ棒（勝利は赤、敗北は青）と日付ラベルを表示します。試合のない日は空白のままにし、7日を超える検索期間でもグラフだけは末尾7日間を表示します。勝敗数、勝率、対戦一覧などの集計範囲は従来どおりフィルター全体です。

戦績モニターと表示ウィンドウ／オーバーレイには、現在のキャラクターの直近20試合を対象にしたMR/LP中央値を独立カードの「POTENTIAL MR／POTENTIAL LP」として表示します。2試合未満では値を表示せず、対象試合数だけを示します。偶数件で中央値が小数になる場合は四捨五入して整数表示します。対戦履歴画面にも、表示対象・期間・モード・キャラクターの絞り込みに連動したPOTENTIAL MR／POTENTIAL LPを表示します。これは公式の別レーティングや実力の確定値ではなく、一時的な上振れ・下振れを把握するための参考値です。

中央値は直近の同一キャラクターのレート帯を表すため、単発の大きな勝敗に引っ張られにくく、現在の実力帯を確認する補助になります。公式サイトが提供するMR・LPそのものではありません。

![対戦履歴画面の例（合成データ）](images/match-history-example.png)

対戦一覧は1ページ10試合です。「前へ」「次へ」でページを切り替えられます。自分のMR/LPは自分のキャラクターの直後に表示されます。

手動の「100件を取得」はUSER CODEごとに10分間隔で制限されます。取得は最大100件（10件/ページ、最大10ページ）で、ページ間も通信キューの安全な間隔を通過します。取得中は現在のページと取得済み件数を表示し、1ページを取得するたびに、その時点の履歴・集計・グラフを更新します。途中で通信に失敗しても、取得済みページはローカル履歴に残ります。通常の「計測を開始」後に行われる既存の定期確認でも、取得できた対戦は同じ履歴へ重複なく保存されます。別プレイヤーを表示している間は、自分の計測と同じ更新間隔（2・3・5分）で対象プレイヤーの対戦履歴を確認し、新しい対戦だけをローカルへ追加します。30分間新しい対戦がなければ5分間隔へ抑制し、60分間なければ対象プレイヤーの自動確認を停止します。

ランキングは初期表示時、キャラクターまたはHOMEの変更時、新しいランクマッチでMRが変動した時だけ更新します。複数試合をまとめて取り込んだ場合も、ランキング更新は1回だけです。別プレイヤーのUSER CODEを表示対象に設定した時は、そのプレイヤーの公式プロフィールを1回再取得し、現在キャラクターの総合MR順位を表示します。ランキングページのHOME別順位はログイン中プレイヤー専用のため、別プレイヤーには適用しません。非MASTERまたは順位を取得できない場合は「—」を表示します。

履歴はWindowsのユーザーごとのアプリ用データ領域に保存されます。アプリの「ローカルデータを消去」またはアンインストール時のデータ削除で消去できます。

## 別のプレイヤーを表示する

ログイン中であれば、「表示対象USER CODE」に別のプレイヤーのUSER CODEを入力して「表示対象を設定」を押せます。公式サイトでそのコードが見つかった場合、選択したプレイヤーの保存済み履歴を表示し、「100件を取得」でそのプレイヤーの最新履歴を取得できます。

別プレイヤーを表示している間は、管理画面の戦績モニターと表示ウィンドウ／オーバーレイも選択したプレイヤーの履歴を読み取り専用で表示します。計測の開始・停止・リセットはできません。「自分のプレイヤーに戻す」でログイン中のプレイヤーへ戻せます。

履歴はプレイヤーごとに別ファイルへ保存されます。保存場所は`%LOCALAPPDATA%\MatchSessionOverlay\user-data\match-history\<USER CODE>.json`です。ログイン情報やCookieはこの履歴ファイルには含まれません。同じコードの検索は10分間キャッシュされ、短時間に検索リクエストを増やしません。対戦確認は既存の通信キューと最短間隔制限を通過します。

「最近の対戦」または対戦一覧の相手名をクリックすると、その対戦相手のUSER CODEを表示対象へ設定し、対象プレイヤーの履歴を取得します。相手USER CODEが履歴に含まれない古い保存データでは、相手名はクリックできません。
