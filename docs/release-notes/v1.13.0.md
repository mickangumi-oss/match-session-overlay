# Match Session Overlay v1.13.0

v1.12.1からの追加・改善です。

## POTENTIAL MR

- `POTENTIAL MR`を、対戦相手のMRと勝敗から、同じキャラクターのRanked Match直近最大100試合を使って推定する方式に変更しました。
- 対戦履歴、グラフ、相手情報で同じ`POTENTIAL MR`方式を使用します。
- 相手プロフィールは、表示最大20試合と、`POTENTIAL MR`計算最大100試合を分けて扱います。
- 選択試合より後の試合、同時刻の試合、選択試合そのものは、相手の`POTENTIAL MR`計算に含めません。
- `POTENTIAL LP`は従来のロバスト方式を維持しています。
- 有効なデータが2件未満の場合は、`POTENTIAL MR`を表示しません。

## ACT履歴の取得

- ACTを切り替えたとき、未取得のACT履歴だけを必要に応じて取得し、取得済みの履歴は再利用するようにしました。
