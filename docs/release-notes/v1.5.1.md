# Match Session Overlay v1.5.1

## 表示とリサイズ

- ウィンドウとオーバーレイで、カード内の見出し・数値・補足情報の文字サイズと位置を揃えました。
- オーバーレイのフォントカラー設定を、数字だけでなくカード内の見出しや補足情報にも反映するようにしました。
- CHARACTER RANKの順位と順位変動を見やすく調整しました。
- SESSION PEAKはウィンドウとオーバーレイで数値を簡潔に表示します。
- アプリ内の数値は、桁区切りカンマを表示しない形式へ統一しました。
- 横表示では、グラフON／OFFでカードの高さが変わらないようにしました。
- 縦表示でグラフをOFFにした際の下部余白を解消しました。
- 表示項目を変更した後も現在のウィンドウサイズを維持し、横表示を同じ最小幅まで縮小できるようにしました。

## English

### Display and resizing

- Card headings, values, and supplemental text now use consistent sizing and alignment in window and overlay modes.
- The selected overlay font color now applies to card headings and supplemental text as well as numeric values.
- CHARACTER RANK and its movement indicator are easier to read.
- SESSION PEAK uses a more compact value in window and overlay modes.
- Numeric values throughout the app no longer use grouping commas.
- Horizontal cards now keep the same height when the graph is turned on or off.
- Extra space below vertical cards has been removed when the graph is turned off.
- The current window size is preserved when display fields change, and horizontal layouts can be resized to the same minimum width.
