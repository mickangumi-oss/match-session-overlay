# Match Session Overlay v1.5.0

## 表示とウィンドウ

- 初回起動時に、日本語／Englishの言語を選択できるようにしました。
- オプション内の言語設定名を`Language`へ統一しました。
- ウィンドウとオーバーレイの初期サイズを約10％縮小しました。
- 表示項目を追加・削除したときも、現在のウィンドウサイズと位置をできるだけ維持します。
- 縦表示でグラフをOFFにした際に残っていた余白を解消しました。
- リサイズ処理を変更し、縦表示でカードを追加した際はグラフが下へ移動するようにしました。
- フォントサイズの設定範囲を30％からに変更しました。

## 対戦履歴と処理性能

- 対戦履歴は取得できたページから、一覧・集計・グラフへ順次反映します。
- 表示・取得処理のパフォーマンスを改善しました。
- 履歴・セッション情報の保存処理を見直しました。
- 同じプレイヤーを短時間に選び直した際のプロフィール重複取得を抑えました。

公式サイトへの通信回数と最低1.5秒間隔は従来どおり維持しています。

## アップデート

- 更新ファイルの検証方法を強化しました。

## ドキュメント

- 英語版READMEと英語版利用ガイドを追加しました。

## English

### Display and windows

- You can now choose Japanese or English when you launch the app for the first time after installation.
- The language setting in Options is now labeled **Language**.
- The initial window and overlay size has been reduced by approximately 10%.
- The app now tries to preserve the current window size and position when display fields are added or removed.
- Extra space that remained when the graph was turned off in vertical view has been removed.
- Resizing behavior has been revised so that the graph moves down when cards are added in vertical view.
- The minimum font-size setting is now 30%.

### Match history and performance

- Match history is now added progressively to the list, summaries, and graphs as each page is retrieved.
- Display and data retrieval performance has been improved.
- Session and match-history storage has been revised.
- The app now avoids fetching the same player's profile repeatedly when you reselect them within a short period.

The existing minimum 1.5-second interval between requests to the official website remains unchanged.

### Updates

- Update-file verification has been strengthened.

### Documentation

- An English README and an English usage guide have been added.
