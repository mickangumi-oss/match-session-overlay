# Match Session Overlay v1.0.13

## 不具合修正

- LPグラフの左側に表示する数値ラベルが重なり、読みにくくなる問題を修正しました。
- LPの値が近い場合でも、0から最大値までのグラフ全体に合った目盛り間隔を使うようにしました。
- 計測開始時のLP基準値が0として扱われ、実際のLP増減より大きな値が表示される場合がある問題を修正しました。
- 既存の計測状態にLP 0のプレースホルダーが残っている場合も、最初の正のLP履歴を基準値として再計算するようにしました。

## 機能追加・改善

- 管理画面を最小化または閉じても、表示中の戦績ウィンドウとOBS用オーバーレイを維持するようにしました。
- 管理画面を閉じた場合は通知領域に隠れ、戦績表示はユーザーが明示的に閉じるかアプリを終了するまで継続します。
- LPの初期値から現在値を正しく差し引き、計測中のLPデルタを表示します。
