# Match Session Overlay v1.3.0

## 対戦キャラクター別成績

- 対戦履歴に、相手キャラクターごとの対戦数、勝数・敗数、勝率を追加しました。
- 日付、対戦モード、自分のキャラクターによる絞り込み結果全体を集計します。
- 全キャラクターを1つの一覧で確認でき、「対戦数」または「WIN RATE」を選んで昇順・降順に並び替えられます。

## MR／LP履歴

- MASTER帯の対戦履歴でもMRとLPをそれぞれ保存し、MRの推移とLPの推移を別々に確認できるようにしました。
- LPグラフの目盛りを読みやすく調整しました。
- 戦績モニター、通常ウィンドウ、オーバーレイのレート表示は、これまでどおりMASTER帯ではMRを使用します。

## 対戦一覧

- 自分のプレイヤー名を省き、相手名、使用キャラクター、レートを確認しやすい表示へ調整しました。
- デスクトップ幅では、1ページ10件の対戦を確認しやすい高さを確保しました。

## オプション

- メンテナンスに現在のアプリバージョンを表示するようにしました。
- ローカルデータを削除したときに消去される内容と、残る設定を画面上で確認できるようにしました。
- フレンド通知の「ゲーム起動中のみ」にはゲームの実行ファイル登録が必要であることを、通知設定内に表示するようにしました。
