# Match Session Overlay v1.9.0

## 対戦履歴グラフの改善

- 勝敗の推移を、試合をした日が新しい順に最大7日分表示するようにしました。
- 同じ日に複数試合をした場合は、勝利・敗北・引き分けを1本の積み上げ棒に集約します。
- グラフ上部の総試合数を、表示中の7試合日の合計に合わせました。

## MR／LP推移の表示切り替え

- MR／LPグラフの上部に共通の操作エリアを追加しました。
- 表示期間を「全期間／週別」、日付表示を「プレイ日のみ／全日」から選択できます。
- 週別ではローカル時間の週境界に沿って前週・次週へ移動できます。
- 全日表示では、試合がない日は直前のMR／LPを引き継ぎ、期間開始前は空白として表示します。

## 表示と増減の修正

- 対戦履歴の最終試合のMR／LP増減を、現在のMR／LPとの差分で表示するようにしました。
- 縦型オーバーレイのキャラクター順位ラベルを、他の項目と同じ左位置に揃えました。

## English

### Match-history chart improvements

- The match-result trend now shows up to seven distinct played dates, ordered from oldest to newest.
- Multiple matches on one day are combined into a single stacked bar for wins, losses, and draws.
- The total shown above the chart now matches the displayed seven-day set.

### MR/LP trend controls

- One shared control area now sits above both the MR and LP charts.
- Choose an all-time or weekly period, and show played days only or every calendar day.
- Weekly mode follows local-week boundaries and supports previous/next week navigation.
- In all-day mode, days without matches carry the previous MR/LP value; dates before the first value remain blank.

### Display and delta fixes

- The latest match's MR/LP change now uses the difference from the current MR/LP value.
- Vertical overlay character-rank labels now share the same left alignment as the other metrics.
