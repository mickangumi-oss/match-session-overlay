# Match Session Overlay v1.0.8

## 不具合修正

- 戦績モニター、通常ウィンドウ、オーバーレイで、POTENTIAL MR／POTENTIAL LPの表示が枠からはみ出したり、試合数表示と重なったりする場合がある問題を修正しました。
- 縦／横レイアウトやウィンドウサイズを変更した際に、グラフや数値が引き伸ばされる問題を修正しました。数値の縦横比とグラフのアスペクト比を維持します。
- キャラクターを切り替えた際に、別キャラクターの試合数・MR・LP・グラフが混ざる場合がある問題を修正しました。
- 対戦履歴の勝敗、相手レート、自分のレートの表示順を整理し、履歴をページ送りできるようにしました。

## 機能追加・改善

- 直近20試合（2試合以上）の同一キャラクターのMR／LP中央値を、POTENTIAL MR／POTENTIAL LPとして独立表示します。偶数件で小数になる中央値は四捨五入します。公式レーティングではなく、短期的な実力の目安です。
- 中央値は単発の大きな勝敗の影響を平均より受けにくいため、現在のキャラクターのレート帯を把握する補助になります。公式サイトのMR／LPを置き換える値ではありません。
- 公式サイトの最新100件の対戦履歴を、USER CODEごとにローカル保存できるようにしました。期間、対戦モード、キャラクターで絞り込み、勝敗グラフと対戦一覧を確認できます。
- ログイン中のプレイヤーとは別のUSER CODEを読み取り専用で表示し、最近の対戦や対戦一覧の相手名から対象を切り替えられるようにしました。
- 管理画面に最近の対戦5件を表示し、対戦履歴画面では10件ずつページ送りできるようにしました。
- GitHub Releasesから取得したインストーラーは、公開されたSHA-256と一致した場合だけ実行します。

画面写真はすべて説明用の仮データです。実在のプレイヤー名、USER CODE、ログイン情報、戦績は含めていません。
