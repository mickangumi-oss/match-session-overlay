# Match Session Overlay v1.6.0

## POTENTIAL MR／LP

- POTENTIAL MR／LPの算出方法を見直し、直近の実力変化へより早く追従するようにしました。
- 一時的な連勝・連敗などによるレート変動の影響を抑えながら、現在の実力帯を確認しやすくしました。
- 管理画面、ウィンドウ、オーバーレイ、OBS、対戦履歴で同じ算出結果を表示します。
- POTENTIAL MR／LPはアプリ独自の参考値であり、公式のレートや将来到達するレートを示すものではありません。
