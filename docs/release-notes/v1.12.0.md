# Match Session Overlay v1.12.0

v1.11.1からの追加・改善です。

## 追加・改善

- 対戦履歴でACTを選択し、ACTごとの履歴・集計・相手情報を確認できるようにしました。
- 選択した試合のラウンド結果を表示できるようにしました。
- 選択した試合について、自分と相手のバトル傾向・ラウンド傾向を比較できるようにしました。

## 対戦履歴の取得改善

- 保存済みの対戦履歴を先に表示し、キャラクター名などの補足情報は表示後に更新するようにしました。
- 最大100件の対戦履歴取得で、同じ対象・言語・取得範囲の通信を共有し、重複取得を抑えるようにしました。
- ACTを切り替えたときは、ACTごとの情報を分けて扱い、同じACTへ戻った場合は有効なキャッシュを再利用するようにしました。
