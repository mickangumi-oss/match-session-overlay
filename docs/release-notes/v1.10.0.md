# Match Session Overlay v1.10.0

## 追加・改善

- 対戦履歴を最大10ページ・100件まで同時取得できるようにしました。
- 取得中のページ数・件数を表示し、取得完了後は完了状態を表示するようにしました。
- 対戦一覧を横幅いっぱいに表示し、勝敗グラフ・MR/LPグラフ・対戦キャラクター別成績を下部へ整理しました。
- 対戦一覧の右端にリプレイIDを追加し、クリックでコピーできるようにしました。
- 対戦行を選択すると、相手プロフィールの参考情報を表示できるようにしました。
  - 対戦時のキャラクター、MR/LP、対戦実績
  - 現在Actの現在値・最高値
  - 別キャラクター名と最高MR/LPまたは現在MR/LP
- 相手プロフィールの値は現在Actだけを対象にし、過去Act・不明な値・MR/LPの混在は表示しないようにしました。

## 以前から存在していた不具合の修正

- 対戦一覧で引き分けが`—`表示になる問題を修正し、`D`として表示するようにしました。
- 最終試合後の公式MR/LPがPOTENTIAL MR/LPや推移表示へ反映されない問題を修正しました。
- 日付境界付近の試合が勝敗グラフ上で誤った日付に集計される問題を修正しました。
- ログイン後、認証状態が未確認のまま残る場合がある問題を修正しました。

今回の開発中に発生した内部的な不具合、テスト専用の修正、リリース作業上の調整は記載していません。

## English

### New and improved

- Battle history can now fetch up to 10 pages and 100 matches concurrently.
- Import progress and a persistent completion state are now shown.
- The match list now uses the full available width, with the charts and opponent-character results arranged below it.
- Replay IDs are shown in the last column and can be copied by clicking them.
- Selecting a match row shows an opponent profile reference card with match-time character/MR/LP, local record, current-Act values, and other-character ratings.
- Past Acts, unknown values, and mixed MR/LP values are kept out of the current-Act reference.

### Fixes for issues carried from earlier releases

- Draws now appear as `D` instead of `—` in match-history rows.
- The final official MR/LP value is now included in POTENTIAL MR/LP and trend displays.
- Matches near the local date boundary are now grouped under the correct date.
- Fixed cases where the account remained unverified after login.

Internal issues found and fixed during this release cycle, test-only changes, and release-operation adjustments are not listed.
