# Match Session Overlay v1.2.0

## フレンドのオンライン通知

- FRIENDSのプレイヤーがOFFLINEからONLINEへ変わったとき、画面右下へ1回だけ通知する機能を追加しました。
- 通知はゲームやほかのアプリのフォーカスを奪わず、マウス操作も妨げません。
- 複数人が同時にオンラインになった場合は、1枚の通知にまとめて表示します。
- 通知するタイミングを「常に通知」または「ゲーム起動中のみ」から選べます。
- 「ゲーム起動中のみ」を使用するには、アプリ設定でゲームの実行ファイル（.exe）を登録してください。未登録の場合はゲームを起動していても通知されません。「ゲーム起動検知」はONにする必要はありません。
- Windows標準サウンドから通知音を選び、試聴できるようにしました。
- PC全体の音量とは別に、通知音だけの音量を調整できます。
- 通知の表示時間と背景の透明度を、通常ウィンドウやオーバーレイとは別に設定できます。文字は透明になりません。
- 合成データを使ったサンプル通知で、現在の設定を確認できます。

通知対象はFRIENDSのみです。初回確認時にすでにオンラインのプレイヤーは通知せず、その後OFFLINEからONLINEへ変わったときに通知します。

exe未登録中に発生したオンラインへの変化は、あとからexeを登録しても遡って通知されません。

オンライン状態は、設定した戦績取得間隔と同じ周期で確認します。管理画面を閉じていても通知がONならFRIENDSの確認を継続し、通知がOFFなら取得を停止します。停止中の変化を後から通知することはありません。オンライン判定はFRIENDSの全ページを正常に取得できた時点で行い、初回取得、取得途中、通信失敗時には通知しません。戦績モニターの計測停止とは連動しません。

## 対戦履歴

- ほかのプレイヤーの対戦履歴は、プレイヤーごとに最新100件を保存するようにしました。
- 100件を超えた古い履歴は自動的に整理されます。
- 自分の対戦履歴は、これまでどおり最大5000件まで保存します。
