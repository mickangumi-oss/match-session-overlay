# Match Session Overlay v1.8.0

## 表示の改善

- アプリロゴを刷新し、管理画面の文字、余白、戦績グラフを読みやすく調整しました。
- 縦型オーバーレイの順位表示を改善し、桁数が多い場合も順位と変動を確認しやすくしました。

## 緊急修正

- 計測中に新しい対戦を取得しても、管理画面の直近の対戦履歴が詳細画面を開くまで更新されない問題を修正しました。
- この修正を確実に適用するため、v1.8.0は強制アップデートとして配信します。

### Display improvements

- The app logo has been refreshed, with more readable management-screen typography, spacing, and match-performance chart sizing.
- Vertical overlays now keep long character rankings and rank movement easy to read.

### Critical fix

- Fixed an issue where newly detected matches did not appear in the management screen's recent-match table until the detailed history screen was opened.
- v1.8.0 is delivered as a required update so this fix is applied consistently.
