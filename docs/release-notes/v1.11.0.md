# Match Session Overlay v1.11.0

前回公開版 v1.10.0 からの主な変更です。

## 追加・改善

- 対戦行を選択すると、相手本人がその対戦で使用したキャラで、対戦前に行った直近最大20試合の勝敗と試合数を確認できるようにしました。
- 相手本人の同キャラ・対戦前の直近最大20試合を基に、POTENTIAL MR／LPを別々に算出して表示するようにしました。対戦前の履歴から算出したアプリ内の目安で、必要な履歴が不足している場合は`—`で表示します。
- 選択した試合の相手情報を保存し、履歴を再読み込みしても同じ結果を表示するようにしました。
- 相手プロフィールカードの情報を整理しました。
- 相手詳細カードの長い数値を、画面幅に合わせて自動で縮小表示するようにしました。

## 以前から存在していた不具合の修正

- 相手の別キャラ最高MRが表示されない場合がある問題を修正しました。
- 計測中にセッションを更新すると、計測ボタンの色が戻る問題を修正しました。

---

## English

Main changes since v1.10.0.

### New and improved

- Selecting a match now shows the wins, losses, draws, and count from the opponent's last up to 20 matches before that match, using the character they used in the selected match.
- The opponent's character-specific POTENTIAL MR and LP are calculated separately from up to 20 of their matches before the selected match. They are in-app estimates based on that history; insufficient history is shown as `—`.
- Opponent details for the selected match are saved so reopening the history shows the same result.
- The opponent profile card information was streamlined.
- Long numbers in the opponent detail card shrink automatically to fit the available card width.

### Fixes for issues carried from earlier versions

- Fixed cases where the opponent's peak MR for another character was not displayed.
- Fixed the tracking button color reverting after a session refresh while tracking.
