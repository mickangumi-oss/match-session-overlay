# Match Session Overlay v1.7.0

## UI・デザインの変更

今回のアップデートでは、アプリ全体のデザインを刷新しました。

以前のデザインを気に入っていた方もいるかもしれませんが、深夜のランクマッチでも目に優しい、落ち着いた配色へ変更しています。利用者の多くが、夜更かしと連敗のダメージを知る大人のプレイヤーであることを信じての調整です。

- 管理画面、対戦履歴、ウィンドウ、オーバーレイ、フレンドオンライン通知のUIデザインを刷新しました。
- 配色、枠線、余白、文字サイズ、グラフ表現を統一し、情報を確認しやすいレイアウトへ変更しました。
- ウィンドウ・オーバーレイの縦表示／横表示を調整し、表示項目やウィンドウサイズに応じて見やすく配置されるよう改善しました。

## 計測状態の表示

- 計測中は、計測ボタンに点灯アニメーションを表示するようにしました。
- 計測中か停止中かを、管理画面から判別しやすくしました。
- プレイヤー情報を再取得するボタンの名称を「セッション更新」へ変更しました。

## 対戦履歴

- 対戦履歴の取得状況を、進捗表示で確認できるようにしました。
- 最終更新時刻を表示するようにしました。
- 管理画面に表示される最新5件の対戦履歴へ、使用キャラクターとMR／LPの増減を追加しました。
- 勝敗グラフ内に、勝利数と敗北数を表示するようにしました。
- キャラクター別勝率を、50％以上と50％未満で色分けするようにしました。

## ウィンドウ・オーバーレイ

- 表示項目を減らした際、不要になった表示領域を自動的に詰めるよう改善しました。
- 表示項目を追加した際は、必要な範囲だけウィンドウを拡張するよう調整しました。
- オーバーレイの操作ボタンを、マウスオーバー時のみ表示するようにしました。

## English

### UI and design refresh

This update introduces a new visual design throughout the app. The calmer MIDNIGHT GLASS palette is intended to be easier on the eyes during late-night ranked sessions. We are choosing to believe that most users are grown-up players who already understand the combined damage of staying up too late and going on a losing streak.

- The management screen, match history, window, overlay, and friend-online notification now share the new design.
- Colors, borders, spacing, typography, and chart presentation have been unified for easier reading.
- Horizontal and vertical window/overlay layouts now adapt more cleanly to the selected items and window size.

### Tracking status

- The tracking button now softly pulses while session tracking is active.
- The player-data refresh action is now labeled **Refresh session**.

### Match history

- Loading progress and the last update time are now visible.
- The latest five matches on the management screen now include the selected character and MR/LP change.
- Win and loss totals are displayed inside the result chart.
- Opponent-character win rates use different colors for results at or above 50% and below 50%.

### Window and overlay

- Removing display items now compacts unused window space automatically.
- Adding items expands the window only as much as needed.
- Overlay controls appear on mouse hover.
