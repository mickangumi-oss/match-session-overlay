# Match Session Overlay v1.13.1

v1.13.0からのユーザー向け変更です。

## 改善

- 対戦履歴の必要なページを最大3件ずつ取得し、履歴の読み込み待ち時間を抑えます。

## 不具合修正

- 対戦履歴の読み込み中に選択した試合が後続ページの到着で一覧から消え、選択状態が失われることがある問題を修正しました。
- データ比較に必要な情報が揃っていても、画面上部が`PARTIAL`になることがある問題を修正しました。
- 選択した試合のAct情報を正しく引き継げず、POTENTIAL MRなどが表示されないことがある問題を修正しました。
